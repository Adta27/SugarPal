# SugarPal
SugarPal is an AI-powered, kid-friendly diabetes companion app for kids and teens with Type 1 diabetes. It helps users log food, mood, activity, and glucose information in a simple, encouraging way, while using a Daily Digest feature to help them notice lifestyle patterns and build confidence with diabetes management.
